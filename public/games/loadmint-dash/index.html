The embedded version of this game doesn't play nice with the page's layout on mobile browsers. Once you believe you've stared at the credits and instructions for an appropriate amount of time, rotate your phone to landscape mode and press the "play" button below to start the game.

A crappy little endless runner by yours truly, effectively a clone of the Chrome dinosaur game featuring my good friend sylvie's fursona. Made in one day as a sort of gift to welcome them into nekoweb.

CC0 public domain license in the sense that you're free to put this up on your website without asking if you really want to for some reason, but son't expect me to release the actual GameMaker source code as it is kind of a mess.

How to play: Use the UP Arrow or TAP the screen to jump over various obstacles for as long as you can. That's it.
